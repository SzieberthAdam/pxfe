**Names in the code now follow the renamed keys** (your mid-task request):

| Was | Now |
| --- | --- |

The source format's own family name (BDF `FAMILY_NAME`, the outline name table) keeps its name, since that is a property of the source file, not of pxtf. The import and New Font dialogs now label the field "Typeface" instead of "Family".

**What else changed:**
- **Files:** typeface files have the `NAME` top line, and every variant has `SOURCE-FORMAT`, `SOURCE-HASH` and `SOURCE-TYPE`. Files with version 1 lines or the `FAMILY` key are refused.
- **Database:** pxfdb is now format version 2. A version 1 database is refused with the message "import the library folder again", so existing `.pxfdb` files have to be rebuilt from their folders.
- **No source format shown:** it is gone from the font cards, the typeface box headers, the Typeface view and META.
- **Typeface name:** META has a Name field as its first row. For a typeface that isn't open, if it is unlocked, editing the name renames it in the library straight away.
- **New Typeface** gives the name "New Typeface", then "New Typeface 2", and so on, because two empty typefaces with the same name would be the same file.
- **Add Font** copies the source lines and reading options from the font's old variant. A font with no old variant gets the editor's source lines.

**Tests and docs:**
- The test data was regenerated, and the old typeface hashes were replaced in the tests. Test Sans is now `ff6354ce…` and Uncoded Mono `0021a99d…`.
