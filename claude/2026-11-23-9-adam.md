**How it behaves:**

- **Save** writes new files to the folder and deletes ones that are no longer used.
- **When the window gets focus, after Load, and on File → Sync with Folder**, pxfe reads the folder:
  - files added or removed there are brought into the library;
  - with no unsaved edits, the changes are applied and saved;
  - with unsaved edits, it asks first (Later / Apply), and "Later" isn't asked again for the same changes.
- **Conflicts:** pxfe remembers which files both sides last agreed on, so neither side undoes the other's pending changes.
  - A file that can't be loaded is reported, left out and never deleted.
  - Files outside the five library folders are never touched.
  - Something still in use, or open in the editor, is kept.
- **The link** is stored in the settings sidecar, pxfdb.pxfdb stays beside the repo, and the status bar shows "linked: <folder>".
- **No git commands are run:** add, commit and push stay manual, as agreed.

**Limits:**

- Files are compared by name only, so a file edited in place under the same name isn't noticed.
- In normal use, the focus check reads the folder in the background (0.3–0.9 s on the real library). Test scripts run the check directly, so that background path isn't tested.
- The first link brings in everything in the folder and keeps everything in memory, then writes the memory-only files to the folder at the next Save.
