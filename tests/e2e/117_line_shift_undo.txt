# 117. The Line tool (version 17), font 3b52125b unlocked, glyph U+0020 (empty, advance 4; font box rows 0..7, @ecell:x,y).
# A drag draws one line, one undo step; Shift constrains the angle (0, 14, 27, 45, 63, 76, 90 degrees, clean slopes), Ctrl draws from the centre,
# Esc cancels, the right button draws with '.', the key L and the strip's Line and Curve buttons.
wait 5
click @Unlock
wait 4
sleep 600
dblclick @cell:U+0020
wait 5
assert editor_glyph U+0020
assert glyph U+0020 empty
assert undo 0
assert epp 0

# the tool: key L, the button, the Curve button
key l shift
wait 3
assert etool 2
assert w.Curve 1
assert w.Pixel-perfect 1

# a plain line: 6 cells in one undo step
drag @ecell:0,1 @ecell:5,1
wait 3
assert glyph U+0020 ink 6
assert glyph U+0020 pixel 0 1 0
assert glyph U+0020 pixel 5 1 0
assert glyph U+0020 pixel 6 1 .
assert undo 1
key z ctrl
wait 3
assert undo 0
assert glyph U+0020 empty

# Shift: nearly horizontal (5 right, 1 down) goes to the 14 degree slope of 4:1, one whole step of it
drag @ecell:0,6 @ecell:5,7 shift
wait 3
assert glyph U+0020 pixel 0 6 0
assert glyph U+0020 pixel 4 7 0
assert glyph U+0020 pixel 5 7 .
assert glyph U+0020 ink 5
key z ctrl
wait 3
assert glyph U+0020 empty

# Shift: 8 right and 1 down is under 7.5 degrees: it goes flat, to the cell on the press row

wait 3

assert glyph U+0020 pixel 7 3 0
assert glyph U+0020 pixel 7 4 .
assert glyph U+0020 ink 9
key z ctrl
wait 3

# Shift: 4 right and 5 down is nearer 45 degrees than 63: the end is the diagonal's 5th step
