# 108. The glyph view's Glyph tab edits the glyph: code point, character, advance, offset x and y (font fa96e358: space, A, H, a default, and two glyphs
# without a code point; KERNING A #0 -1 and #1 #0 +1).  Locked, the fields are dim and inert.  A code another glyph has, the default glyph's code and a
# number that is no code point are refused; a new code moves the glyph to its place in the order, keeps the editor on it, and its kerning pairs follow.
wait 5
click @cell:U+0041
key enter
wait 6
assert editor 1
assert gtab 0
assert eglyph U+0041
assert w.g.code 1
assert w.g.char 1
assert w.g.advance.value 1
assert w.g.offx.value 1
assert w.g.offy.value 1
assert readonly 1
